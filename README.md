# SMARTAI Dashboard

Portal antarmuka member Smart AI untuk demonstrasi UI.

**Preview:** https://luqmanhakimh23-create.github.io/SMARTAI-Dashboard/

## Status proyek

Saat ini repositori ini adalah **prototype frontend statis**. Login, pendaftaran, profil, angka dashboard, performa, laporan, referral, komisi, dan transaksi menggunakan data contoh di browser. Tidak ada sinkronisasi server, broker, MT4/MT5, pembayaran, atau pemrosesan uang.

> **Penting:** label demo ditampilkan di setiap halaman agar data simulasi tidak disalahartikan sebagai hasil, saldo, akun aktif, atau transaksi nyata.

## Fitur antarmuka

- Login dan pendaftaran untuk preview lokal.
- Dashboard ringkasan dengan data ilustratif.
- Halaman performa dan laporan dengan data contoh.
- Daftar klien, referral, komisi, transaksi, support, dan profil.
- Tema gelap/terang dan layout responsif.
- Halaman pemberitahuan risiko dan privasi.

## Batasan keamanan

- Autentikasi saat ini hanya simulasi berbasis `localStorage`; bukan autentikasi produksi.
- Data browser dapat dibaca atau diubah oleh pemilik perangkat. Jangan masukkan kata sandi asli, data keuangan, atau informasi pribadi sensitif.
- Kredensial demo yang tersedia di source code bersifat publik dan tidak boleh dipakai ulang untuk layanan lain.
- GitHub Pages adalah hosting statis; jangan gunakan untuk menyimpan password, data pembayaran, atau informasi rahasia.
- Integrasi backend, autentikasi server, database, dan koneksi data eksternal belum tersedia.

## Risiko

Contoh angka, grafik, dan riwayat bukan bukti performa atau jaminan hasil. Aktivitas pasar memiliki risiko kerugian. Jangan mengambil keputusan keuangan berdasarkan data demonstrasi.

## Menjalankan preview

Buka `index.html` melalui GitHub Pages atau server statis lokal. Untuk pengembangan lanjutan, gunakan backend dan peninjauan keamanan yang sesuai sebelum mengumpulkan data pengguna.
